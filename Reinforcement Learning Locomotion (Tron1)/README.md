# 🐾 IsaacGym + W&B Logging (Working Repository)

This repository is a **working version** of the original IsaacGym tutorials,  
with **Weights & Biases (W&B) logging** enabled for experiment tracking 📊.

---

## 🚀 Features
- ✅ Based on official IsaacGym tutorial environment  
- ✅ W&B integration for logging rewards, losses, and episode stats in real time  
- ✅ Docker setup for reproducibility (Ubuntu 20.04 base required)  

---

## 🛠️ Environment Setup
IsaacGym requires **Ubuntu 20.04**.  
Since our team mainly worked on Ubuntu 22.04, we ran IsaacGym through a **Docker container**  
and mounted this repository inside the container for training and logging.
